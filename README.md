## ✨ Features

- ✅ End-to-end audit cycle management
- ✅ 5 accessor roles with fine-grained control assignment
- ✅ Cross-framework control mapping (ISO 27001 ↔ SOC 2)
- ✅ Department-aware RBAC enforcement
- ✅ Live database persistence (PostgreSQL)
- ✅ Professional UI with CLOVRIX branding
- ✅ Enterprise authentication (Keycloak OAuth 2.0)
